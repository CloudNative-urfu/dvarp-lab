## Context

Флаг `allow_remote_llm` — обход локальности эндпоинтов ТОЛЬКО для проверки
работоспособности (прокси AITunnel и т.п.), никогда для статьи (инвариант
8c, NFR-2.4/2.5). Guard тройной:

1. пин `"remote_llm": true` в манифесте прогона;
2. `raw.remote_llm=true` в каждой записи filter;
3. метрики пропускают remote-эпизоды по умолчанию (`include_remote` —
   явная опция `/compute`).

На remote-прогонах L* считается полноценно при явном `include_remote` —
формулы и различия конфигов проверяются на живом материале; в датасет
статьи эти числа не идут.

## Goals / Non-Goals

Goals:

- номинальная проверка допускает remote-эндпоинты только с флагом;
- remote-модели вне ростера: честный model_spec с пометкой
  `revision="remote-verification"`;
- галочка в UI консоли.

Non-Goals:

- remote-прогоны для кампании статьи;
- удаление пинов при повторном запуске — пин обязателен всегда.

## Decisions

- Флаг протаскивается через оси кампании (axis-спека) и CLI, а не через env
  процесса: решение видно в манифесте прогона.
- UI-галочка — тот же флаг спецификации осей (без отдельного канала).
