# Design — stub-structural-stop

- Остановка атакующего — три структурных источника: (1) `ended` от shop в цикле
  эпизода (сессия закрыта СС), (2) исчерпание бюджета, (3) явный DONE живой
  модели — её собственное решение, переданное протоколом, а не подстрочным
  матчингом;
- Stub лишается лексики целиком (`_DONE_WORDS`, `_believes_success` удалены):
  решение по текстам агента — это ровно тот хардкод, который #15 запрещает;
  детали исходов (`attacker_stopped`) остаются достижимы только для live-DONE;
- Фразовые банки stub (`_EVIDENCE`/`_PUSHES`, банки стилей) — не лексика
  решений, а содержимое реплик: их замена не входит в задачу.
