## Context

Атакующий не имеет доступа к коду защиты и БД магазина (инвариант 2
мануала): он видит только текст ответа СС через HTTP. Управляемая
переменная — тактика: стартовый промпт берётся из корпуса, механизм и
цель размечены (FR-1.21). Реестр тактик сгруппирован из корпуса — это
замороженная характеристика, а не код.

## Goals / Non-Goals

Goals:

- реестр тактик как frozen-файл с группировкой по механизму/цели;
- выбор тактики планом прогона (ось кампании), а не моделью;
- детерминированный вывод сидов для раскладки (lab.seeds).

Non-Goals:

- адаптивная память атакующего (усиление поверх тактик) — будущая ревизия;
- доступ атакующего к защите или БД — запрещён по построению.

## Decisions

- `tactics.py` читает `frozen/corpus/tactics.json` — единый источник тактик
  для сервиса и launcher'а; corpus остаётся источником разметки.
- Группировка: mechanism / goal / oververbosity-канал из корпуса v2
  (FR-1.21); реестр плоский для оси кампании.
