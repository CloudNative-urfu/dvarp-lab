## Why

Issue: [CloudNative-urfu/dvarp-lab#20](https://github.com/CloudNative-urfu/dvarp-lab/issues/20).

Атакующий episode_id `{run_id}-A{i}-{tactic}-s{seed}` не содержал стиль, а
`derive_seed` атакующей ноги тоже был без стиля. При оси стилей две ячейки с
одной тактикой и разными стилями давали один id и один сид: filter склеивал их
в один эпизод, пара теряла атакующую ногу, кассеты и трейсы перезаписывались.
С осью целей (#4) было бы то же самое.

## What Changes

- атакующий id собирается от сценарной сигнатуры ячейки: все оси ячейки, кроме
  тех, что различаются в метриках иначе (config, модели) или стоят в id
  отдельно (seed). Сейчас `{run_id}-A{i}-{style}-{tactic}-s{seed}`; ось цели
  войдёт сама, без правки формата;
- сид атакующей ноги выводится из той же сигнатуры;
- легальный id не меняется: `{run_id}-L{i}-{style}-s{seed}` полон по своей
  сигнатуре, совпадение у ячеек одного стиля ожидаемо (один контроль на стиль).

## Impact

- сиды атакующих ног в новых прогонах отличаются от старых при тех же осях;
  старые прогоны не пересчитываются;
- консоль читает id из манифеста, правок не требует.
