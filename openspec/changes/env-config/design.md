# Design: env-config

## Решения

- **Загрузчик — stdlib, не dotenv-библиотека**: зависимость в pyproject не
  тащим (принцип репо — минимум обвязки); парсер покрывает формат шаблона
  (KEY=VALUE, кавычки, `export`, inline-`#`). Порядок: парсим до создания
  dev-процессов; `setdefault` — существующее окружение сильнее файла.
- **Имена моделей — не дефолты**: по дисциплине заморозки ростер живёт в
  `frozen/llm.json`; конкретные имена прокси-моделей в шаблоне — только как
  плейсхолдеры, чтобы дефолты не устаревали и не подменяли замороженные
  характеристики.
- **Переименование в `.env.example`**: симметрично `.env` (gitignore уже
  скрывает только `.env`), uv подхватывает файл с таким именем, если
  запускать с `--env-file`.

## Риски

- inline-`#`-комментарий в значении без пробела перед `#` не отрезается —
  в URL такого нет; шаблон сам генерирует значения с пробелом перед `#`.
