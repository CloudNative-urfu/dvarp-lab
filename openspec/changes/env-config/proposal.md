## Why

Шаблон окружения (`env.example`) был набором закомментированных примеров с
захардкоженными именами моделей прокси, а `uv run` не загружает `.env`
автоматически: при запуске `uv run python scripts/dev.py` сервисы стартовали
без Live-LLM переменных из `.env`, live-режим молча не включался, а UI не
показывал имена remote-моделей. Нужны дефолты без имён моделей (модели —
замороженная характеристика, внешние — только через remote-флаг) и
самозагрузка `.env` в dev-режиме.

## What Changes

- `env.example` → `.env.example`: заполнен рабочими дефолтами (URLs сервисов
  9410–9415, пути SQLite из дефолтов кода); **имена моделей убраны из
  дефолтов** — вместо них плейсхолдеры `<имя-модели-у-прокси>`; пометка, что
  ростер — `frozen/llm.json`, внешние модели — через `allow_remote_llm`;
- `scripts/dev.py` — stdlib-загрузчик `.env` (KEY=VALUE, кавычки, `export`,
  inline-`#`-комментарии): переменные не перекрывают уже заданные в
  окружении; обычная команда `uv run python scripts/dev.py` снова работает
  без явного `--env-file`.

## Capabilities

### New Capabilities
- `env-config`: шаблон окружения с дефолтами без имён моделей и
  самозагрузка `.env` в dev-режиме.
