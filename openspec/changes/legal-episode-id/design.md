# Design — legal-episode-id

- Сигнатура ячейки — общий источник для обеих ног: `attack_signature(cell)`
  (goal-style-tactic в порядке осей) → `legal_episode_id` отличается от
  `attack_episode_id` только маркером L/A. Уникальность обеспечивается
  уникальностью (goal, style, tactic) ячейки (i различает эпизоды ячейки);
- Манифест продолжает ссылаться на id через один источник
  (`cell_result["legal_episode_id"] = legal_id`), `_final_outcome` читает
  финал по тому же id;
- Старые записи raw не трогаем: кампании до фикса остаются пуллеными
  (известное ограничение, отметка в validity — исторические данные демо).
