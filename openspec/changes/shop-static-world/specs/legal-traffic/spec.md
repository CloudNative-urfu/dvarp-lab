## MODIFIED Requirements

### Requirement: Truthful refund cases from shop DB
traffic_svc SHALL строить правдивый запрос на возврат из данных БД магазина,
которую читает read-only; запись в БД магазина из traffic_svc SHALL быть
запрещена. Легальный кейс SHALL быть фиксированным: один всегда-возвратный
заказ A из манифеста мира (`legal_case`) — сид не перебирает заказы;
`reason_code` кейса SHALL читаться из БД (замороженная причина в строке
заказа), рандом прогона причину не выбирает. У легального эпизода варьируется
только ось стиля (инвариант 8b в ревизии «один мир»).

#### Scenario: Fixed legal case
- **WHEN** легальный эпизод запущен с любым сидом
- **THEN** кейс — один и тот же заказ A из манифеста мира; отличается только
  реплики стиля

#### Scenario: Reason from data
- **WHEN** кейс собран
- **THEN** причина возврата прочитана из БД магазина, а не выбрана рандомом

#### Scenario: Read-only access
- **WHEN** traffic_svc обращается к БД магазина
- **THEN** подключение read-only; изменять данные оно не может
