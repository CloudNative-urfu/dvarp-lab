## Why

Корпус атак — замороженная характеристика и источник правды для стартовых
промптов атакующего. Внутри СС нужен зеркальный компонент, который привязывает
записи корпуса (механизм / цель / овервербальность, FR-1.21) к кейсам БД
магазина: атака подействует только на существующий кейс. Переносится из
прототипа (#32, корпус v2).

## What Changes

- `services/shop/corpus/schema.py` — схема записи корпуса (оси разметки);
- `services/shop/corpus/store.py` — загрузка/хранение записей корпуса v2;
- `services/shop/corpus/bind.py` — привязка записей к кейсам БД;
- `services/shop/corpus/dirty.py` — деградация записей (dirty-варианты).

## Impact

- атакующий получает размеченный стартовый промпт, привязанный к кейсу БД;
