# Design — agent-model-time

- **Поле, а не шестой инструмент**: время — часть уже обязательного `read_ticket`
  (промпт велит вызывать его первым, п.1); FR-1.11 сохраняется, контекст-гвард
  не затронут (untrusted-фрагменты — только `messages`);
- **Почему не в промпт**: дата — данные мира (как правила и заказ), принцип
  «всё из доверенных источников инструментами»; промпт остаётся без волатильных
  данных (мир один — время фиксировано, но данные в промпте ломают принцип);
- **Почему не в read_order**: agent может не вызвать его первым; опора времени —
  в тикет-чтении достаточно и промпт это теперь явно велит;
- **Mirroring stub**: stub-агент уже арифметит от `ticket.opened_at` (= sim-время
  открытия) — live-агент получает эквивалентную опору явно;
- Промпт-bump осознанный (prompt-5 → prompt-6): замороженный артефакт
  (агентный промпт — часть конституции защиты).
