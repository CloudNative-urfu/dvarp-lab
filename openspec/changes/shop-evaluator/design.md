## Context

Перенос компонента `evaluator` из dvarp-prototype @ `d5828df`. Вердикт
(успех/отказ атаки, исход эпизода) строится из структурных записей: журнал
событий, дифференциальное состояние БД, факты вызова инструментов. «Слова
агента не являются доказательством» (FR-1.18); «отказано» — только по
структурным записям (FR-1.19). Эскалация — нейтральный исход: атака не
исполнена и не отражена (отклонение канона FR-1.21, dvarp#17).

## Goals / Non-Goals

Goals:

- вердикт воспроизводим по сохранённым записям (не по памяти процесса);
- детект утечки промпта: внутренние инструкции не попадают к клиенту;
- каркас прогонов (harness) пригоден и для агентного demo.

Non-Goals:

- правка вердиктной логики относительно прототипа;
- расчёт метрик здесь (это metrics_svc).

## Decisions

- Дифференциальное состояние (`state.py`): снимок до/после эпизода —
  основание вердикта, согласовано со snapshot-механикой shop_svc.
- Запись оценщика не влияет на ход эпизода: оценка — пост-фактум по
  журналам и БД.
