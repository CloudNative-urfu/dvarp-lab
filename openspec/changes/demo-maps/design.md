# Design — demo-maps

- Рендер без зависимостей: каждая карта — `<svg>` из `rect`/`text`/`line`;
  цвет ячейки — линейная интерполяция красный↔зелёный по нормированному
  значению строки, «плохие» метрики (V/R/E/G-τ) инвертированы (меньше = зеленее);
- Ключ группы — `config/model_name/role`: у конфигурации несколько групп
  (агент/атакующий, разные пины), схлопывание теряло данные (найдено на пилоте);
- Вход — HTTP `/metrics/{config}` metrics_svc: скрипт работает при
  выключенных сервисах (сервис отдаёт из собственной БД результатов) и на
  любой базе через `--metrics-url`;
- Вне измерительного пути: скрипт только читает готовые результаты,
  ничего не пишет в сырую/метрическую БД (сбор ≠ расчёт).
