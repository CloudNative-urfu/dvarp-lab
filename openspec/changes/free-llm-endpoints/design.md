# Design: free-llm-endpoints

## Решения

- **Источник истины о remote — эндпоинт, не флаг.** Launcher смотрит env
  тех же переменных, что читают сервисы (dev.py грузит один `.env` во все
  процессы), и пинит манифест. Каждый сервис дополнительно маркирует свои
  записи по собственному эндпоинту — запись честна даже при расхождении env
  launcher'а и сервиса (CLI-launcher без `.env`).
- **Remote — свойство эпизода.** Metrics собирают множество episode_id,
  у которых хоть одна запись `raw.remote_llm`, и исключают все строки
  эпизода (shop-строки идут с model_spec агента, traffic/attack — со своим).
- **Локально = loopback.** Канон NFR-2.5 и #84 фиксируют 127.0.0.1;
  частные адреса больше не считаются локальными для маркировки.
- **Флаги не удалены**: `allow_remote_llm` остаётся в моделях запросов
  UI/CLI для совместимости, но ни на что не влияет.
- **Размер (NFR-2.6) не тронут**: локальный агент — `check_model_size`
  как раньше; remote — `remote_verification`, неизвестный размер
  требует `RESEARCH_LLM_PARAMS_B`.
