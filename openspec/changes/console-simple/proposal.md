## Why

Issue: [CloudNative-urfu/dvarp-lab#76](https://github.com/CloudNative-urfu/dvarp-lab/issues/76).

Консоль показывает всё, что умеет стенд, и поэтому непонятна человеку со стороны:
режимы осей point/range/set/all_limited на первом экране, стена из ~35 значений
метрик без подписей, отдельные вкладки «Прогоны» и «Трейс» с машинными id, исходы
`completed / executed` без пояснений, у «Системы» слипшиеся значки. На защите
проекта жюри должно за 2–3 минуты понять, что делает полигон и что он намерил.
Команде нужны те же экраны с доступом ко всем прежним настройкам.

## What Changes

- вкладки: Результаты / Диалоги / Запуск / Система (было Запуск / Прогоны / Трейс /
  Метрики / Система);
- «Результаты» — первая вкладка: одна таблица по конфигурациям защиты (атак,
  V «атаки прошли», R «ложные отказы», E «ушло оператору», окупаемость по L*);
  у каждой колонки подпись; строка раскрывается: описание защиты, детекция,
  диапазон L* по ценам пина, «Все значения расчёта» свёрнуты; строки с другим
  числом атак, чем у эталона g0, помечены и стоят в конце; кнопка «Пересчитать
  метрики» с переключателем облачных прогонов;
- «Диалоги» заменяют «Прогоны» и «Трейс»: список пар с фильтрами (защита, исход
  атаки, прогон), исходы по-русски со значком; пара открывается целиком: честный
  клиент и атакующий рядом, цель и метод с описанием;
- «Запуск»: три поля (защита, цель, метод) с описаниями и число пар; объём
  пересчитывается сам; статус прогона в той же карточке, переход к его диалогам;
  оси, модели, сиды, пресеты, бюджет и probe — в «Расширенных настройках»;
- «Система»: сервисы по-русски с назначением, хеш-цепочка с пояснением; отступы;
- `describe.py`: `labels` в `/api/meta` (конфигурации, цели, описания методов из
  `frozen/corpus/tactics.json`, исходы, ключевые метрики, сервисы);
- ui_svc: `GET /api/summary`, `GET /api/pairs` — только чтение;
- стиль: токены отступов и размеров, базовая раскладка — телефон, без цветных
  полос сбоку у реплик.

## Impact

- инварианты 8a (UI — читатель/вызыватель: `/api/summary` и `/api/pairs` только
  выбирают сохранённое), 7 (сбор ≠ расчёт), 1 (барьер: диалог — только тексты
  канала) сохраняются;
- прежние эндпоинты `/api/runs`, `/api/preview`, `/api/metric-*`, `/api/episodes`
  остаются для CLI и скриптов; фронт их больше не вызывает.
