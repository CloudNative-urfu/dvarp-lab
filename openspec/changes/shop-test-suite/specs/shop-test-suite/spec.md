## ADDED Requirements

### Requirement: Defense test suite port
Набор тестов защиты из прототипа SHALL переноситься без ослабления
проверок и покрывать перенесённый код на lab-стеке: агент (FR-1.9/1.10/
1.12, NFR-2.2/2.3/2.7), конфигурации (NFR-2.10/2.12, FR-1.14), оценщик
(FR-1.18/1.19/1.21), исполнитель (FR-1.13/1.14), контракт плагинов
(FR-1.5–1.9, NFR-2.9), плагины, политика, LLM (NFR-2.5/2.6), инструменты
(FR-1.11). Правки кода защиты — только под тестовый контур.

#### Scenario: Same tests, lab stack
- **WHEN** порт-набор запущен на lab
- **THEN** проверки канона проходят без правок логики защиты

#### Scenario: Test isolation
- **WHEN** тесты запускаются в произвольном порядке
- **THEN** `tests/_env.py` изолирует окружение (env, временные каталоги БД)

## ADDED Requirements

### Requirement: Service barrier tests
Сервисный слой СС SHALL проверяться тестами барьера и кампании:
`test_shop_service.py` — ответ `/turn` содержит ровно три поля (текстовый
барьер, инвариант 1), reset/configure детерминированы, снимки снимаются и
восстанавливаются; перенесённые тесты адаптированы к сервисному слою без
ослабления.

#### Scenario: Turn barrier enforced
- **WHEN** `test_shop_service` проверяет ответ /turn
- **THEN** лишние поля в ответе считаются дырой в барьере (инвариант 1)

#### Scenario: Snapshot roundtrip tested
- **WHEN** тест снимает и восстанавливает снимок
- **THEN** состояние БД совпадает с исходным
