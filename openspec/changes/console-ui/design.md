## Context

ui_svc — статическая страница + `/api/*`; инвариант 8a мануала: «консоль —
только читатель/вызыватель, ноль расчётов». Запуск кампаний — через те же
`run_campaign/probe`, что у CLI; расчёт — через `metrics /compute`.

## Goals / Non-Goals

Goals:

- `/api/meta` — свод frozen (оси, guard) + health пяти сервисов;
- `/api/volume` — объём кампании до запуска (cells, episodes);
- `/api/run` — спецификация осей; фоновый поток, один прогон за раз (409,
  если уже идёт); объём сверх guard требует `confirm: true`;
- `/api/run/status` — живой прогресс (стадия, ячейки, текущая ячейка);
- `/api/probe` — одна атака (probe);
- read-only прокси: metrics, text, chain, runs.

Non-Goals:

- расчёты метрик или формул в UI;
- второй механизм оркестрации (только launcher.campaign);
- авторизация/многопользовательность — локальный стенд.

## Decisions

- Один фоновый поток прогона: второй `/api/run` → 409 (конфликты кампаний
  недопустимы — один манифест за раз).
- Статика без сборщика: index.html/app.js/style.css отдаются FastAPI.
