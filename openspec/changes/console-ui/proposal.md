## Why

Консоль нужна для операторской работы со стендом (запуск, прогресс,
эпизоды, метрики, история), но обязана остаться чистым читателем/вызывателем:
любой расчёт или оркестрация в UI дублировали бы логику и порушили бы
инвариант «сбор ≠ расчёт». Прототипная Next.js-консоль сознательно не
переносится — статическая страница на FastAPI.

## What Changes

- `services/ui/` — FastAPI-приложение ui_svc на :9410 со статической
  страницей (index.html, app.js, style.css);
- `/api/*` — читатель/вызыватель: meta, volume, run, probe, status,
  read-only прокси;
- запуск идёт через те же `launcher.campaign.run_campaign/probe`, расчёт —
  через `metrics /compute`.
