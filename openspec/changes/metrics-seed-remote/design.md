# Design — metrics-seed-remote

Сид для сэмплинга каждой ноги остаётся производным; `group_seed` сохраняет
исходный сид ячейки в сырой записи. Группы `(run_id, seed)` строятся после
фильтра probe/remote и отдельно для каждого config × model_spec × mode.
Эталон g0 выбирается по тем же run_id, seed, model_spec, mode; если отсутствует,
статус `no_reference`. В live сид — только метка группы сэмплинга, не гарантия
воспроизводимости ответа LLM.

По умолчанию рассчитывается local. `include_remote=true` публикует раздельные
local и remote и явно помеченный общий `all`, если существуют обе группы;
`n_remote` показывает долю источника. UI ключует карточки по mode.
Миграция колонки добавляется к `create_all` без изменения сырой БД.
