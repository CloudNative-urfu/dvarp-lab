## Context

metrics_svc читает сырую БД filter_svc только read-only и считает формулы
канона (L* — доля успешных нарушений защиты, break-even, detection).
Результаты хранятся в собственной БД metrics_svc: пересчёт в любое время,
правка формул не трогает прогоны. Агрегация — по config × model_spec
(FR-1.23-style).

## Goals / Non-Goals

Goals:

- формулы канона без упрощений, с золотыми значениями в тестах;
- read-only доступ к сырой БД (никаких записей в чужие данные);
- фильтр `/compute` по конфигам — эталонный конфиг берётся из полных данных,
  чтобы L* не вырождался на срезе.

Non-Goals:

- расчёт метрик в сервисах прогона — запрещён (инвариант 7);
- отчёты/таблицы статьи — на этом слое только числа.

## Decisions

- Extraction — свой слой (`extract.py`): сырая БД остаётся чужой, схема
  знает только про записи и каналы.
- Результаты — `MetricRow(config_name, model_spec, …)` в своей БД;
  `GET /metrics/{config_name}` — агрегаты по config × model.
